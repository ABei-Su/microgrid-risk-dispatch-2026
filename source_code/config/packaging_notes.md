# 打包取舍和完整性

只从正式v5调用链复制求解器、因果执行、场景构造、概率压缩、月度策略与必要预处理函数。部分基础函数在原工程冻结目录中保留历史目录名，但当前正式版本实际依赖它们；本包不携带旧版运行入口或旧版年度结果。

包装层为相对路径、结果导出和SHA-256完整性检查而新增，不改变模型。因包布局及无关分支删除，缓存指纹与原工程不同；保留原签名作为溯源，重新求解使用新的隔离缓存，绝不复用伪装成新结果的旧缓存。

data保留原CSV名，删除的只是正式回放不读取的冗余列，无行删除、四舍五入或数值变换。输入投影清单逐列列出；结果CSV逐字节复制。图表目录中与forecast_V2相同的重复输入用路径说明代替；其余结果CSV保留。完整十分钟全年数据由默认运行生成，包内提供代表种子图表轨迹、全部种子的逐日费用/更新/求解日志。

ZIP采用标准ZIP-LZMA无损压缩以满足20MB上限；WinRAR、7-Zip和Python zipfile均可解压。完整性清单不记录个人绝对路径。提交包不含论文、承诺书、编号页、Office作者元数据或本地缓存。
