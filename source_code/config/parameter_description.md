# 最终参数说明

final_config.yaml仅覆盖Q2正式参数，其余保留v5配置；execution_config.json是原执行配置，保留原元数据但不会运行历史实验矩阵。FINAL_MODEL_LOCK.json保留原月度选择依据。

| 参数 | 生效值/解释 |
| --- | --- |
| 随机种子 | 1、2、3、4、5；基础配置42仅是历史默认值，正式回放由外层覆盖 |
| 时间范围 | 2025-02-01至2025-12-31，共334天；1月为历史预热 |
| 时间步长 | 10分钟，每日144槽，1/6小时 |
| Q2场景 | 49条历史联合路径＋1条压力路径；历史各0.96/49，压力0.04 |
| Q3场景 | 保持锁定月度策略；V2/directNet为6场景、风险权重0.06；risk20为20场景、风险权重0.12 |
| Q4压缩 | 50候选=49历史＋1压力；历史至多10个代表，压力独立保留；历史权重按簇频数聚合至总和5/6 |
| CVaR | 置信水平0.95；Q2风险权重0.02；Q4为0.06，Q3按锁定月度配置生效 |
| 残差历史窗口 | 最多56天；只使用当前决策日之前的历史日 |
| 预测输入 | 冻结的滚动分位数预测、V2、directNet及当时已发布的官方PV预报；本次不重训 |
| 电池容量/范围 | 容量12000 kWh；SOC 1200—10800 kWh |
| 功率/效率 | 5000 kW；充电与放电效率均0.9 |
| 初始SOC/目标 | 首日6000 kWh，末端目标6000 kWh；随机回放跨日继承实际SOC，不每日重置 |
| 末端惩罚 | terminal_penalty_factor=0.08；不把软目标宣称为逐日强制终值 |
| 费用系数 | 紧急购电为5倍、上调改签1.5倍、下调退费0.5倍 |
| 更新节点/门槛 | 0、6、12、18时；收益严格大于1元才更新，已执行前缀冻结 |
| 因果执行 | Q2 discharge_fraction=1.0，全时段使用物理可用电量；Q3/Q4保留0.35及21时放开；逐槽核验 |
| 无效动作惩罚 | throughput_epsilon=1e-7；Q1保持原词典序LP |

Q4日前保留共同场景下的候选安全筛选，不仅仅调用压缩器；其正式采用依据见result/Q4/Q4_day_ahead_stability.csv。概率覆盖是抽样历史日覆盖，不是预测区间覆盖。
