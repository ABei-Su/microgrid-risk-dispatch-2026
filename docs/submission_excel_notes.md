# 附件5结果表填报说明

`result/result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx`均由赛题附件5原始模板生成，工作表名称、表头和问题对应关系保持不变。

- `计划购电量`：写入每天0:00确定的144个10分钟计划；最后两列为计划购电量合计和计划购电费。
- `调整购电量`：仅问题三和问题四日内包含，写入滚动更新后最终执行的普通购电量；末列采用计划费用、上调1.5倍费用和下调50%退费的结算口径，不含另表紧急购电费。
- `充放电量`：每天按6个四小时区间汇总充电量和放电量，并给出0:00初始SOC与24:00最终SOC。
- `紧急购电量`：将相邻的正紧急购电槽合并成连续时间段，电量为段内10分钟电量之和。

问题二至问题四的官方结果表采用种子1，因为一个结果文件必须表示一条自洽、可实际执行的完整策略。论文中的年度费用、紧急购电和CVaR95继续采用五个随机种子分别回放334天后的均值。种子1结果不替代论文均值，只承担官方明细表的单策略展示与复现。

附件5的静态时间表头从`0:10-0:20`开始。程序保持官方表头原文，按模型内部槽序将第0至143槽依次写入144个模板列；物理时间、模板列和数据槽的逐项一致性由`source_code/validate_submission.py`检查。
